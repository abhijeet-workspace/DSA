## How to use

1. Finish the [primary study plan](../study_plan.md) core (and optionally [Blind 75](../core_sheet/blind_75.md)) first.
2. Pick your primary company pack; time-box 45–60 minutes per session (2–3 problems).
3. Mark gaps (`—`) and implement missing titles in the matching phase folder when needed.
4. Do a second pack for your backup company.
